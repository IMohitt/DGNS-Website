# Travel imagery

Phase 6 travel photography is stored here as optimized responsive JPEG families.
Each generated source has a 1536 × 1024 full image plus 1000px and 640px
variants for responsive delivery.

Asset families:

- `uae-travel-hero-dubai-desert-coast`
- `ras-al-khaimah-hajar-mountains`
- `fujairah-east-coast-mountains-sea`
- `dubai-desert-safari-dunes`
- `dubai-al-fahidi-heritage-lane`
- `dubai-coastal-spa-relaxation`
- `abu-dhabi-sheikh-zayed-grand-mosque`

These images were generated specifically for this project and inspected for
responsive framing, visible text, logos, watermarks, and identifiable people.
Legacy website screenshots remain content references only; their embedded
travel photographs were not cropped or reused because original files and
licensing were not available. Existing Dubai, Abu Dhabi, Sharjah, and Ajman
destination imagery reused by Phase 6 remains in `../home/`.

Future image upgrades should preserve the current 3:2 responsive families and
truthful alt text. More activity-specific originals would be useful for the
Museum of the Future, Sky Views, JBR, snorkeling, and individual packages.
